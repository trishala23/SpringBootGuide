# Spring Boot Guide

Welcome! This is a hands-on, beginner-friendly tutorial that teaches you
**Spring Boot** from scratch. No prior Spring experience needed — just
basic Java.

We explain things in plain words, and we explain any technical term the
first time we use it. No lesson assumes you remember jargon from a
textbook you may never have read.

## Who this is for

You'll get the most out of this guide if you:

- Know basic Java (variables, classes, methods — you don't need to be an
  expert).
- Have never used Spring or Spring Boot before, or only vaguely know what
  it is.
- Learn best by reading a short explanation, then actually typing and
  running code.

## How to use this guide

- Go through the lessons **in order** — each one builds on the last.
- Each lesson takes about **15–30 minutes**.
- Every lesson has a "Try it yourself" exercise. Actually do it — typing
  the code yourself is how it sticks. The solution is hidden under a
  "Show solution" toggle so you can check your work without seeing the
  answer by accident.
- Runnable code for each lesson lives in the
  [`code-examples/`](https://github.com/trishala23/SpringBootGuide/tree/main/code-examples)
  folder of the repository, one subfolder per lesson.

## What you'll need

- **Java 17** or newer (we'll walk through installing it in Lesson 2).
- **Maven** (also covered in Lesson 2 — Spring Initializr can set this up
  for you).
- A code editor. We recommend **IntelliJ IDEA Community Edition** or
  **VS Code with the "Extension Pack for Java"**, but any editor works.
- About 15 minutes and a working internet connection for the setup lesson.
