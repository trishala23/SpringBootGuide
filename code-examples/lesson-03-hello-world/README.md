# Lesson 3 code example: Hello World

Companion project for
[docs/lessons/03-first-app-hello-world.md](../../docs/lessons/03-first-app-hello-world.md).

## Run it

```bash
mvn spring-boot:run
```

Then visit <http://localhost:8080/hello> — you should see:

```
Hello, World! Spring Boot is running.
```

Stop the app with `Ctrl+C`.
